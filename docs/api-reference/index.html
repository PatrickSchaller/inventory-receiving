What should I look for?

Send a receipt twice: the second result has replayed: true and stock stays unchanged. Change its quantity while keeping its reference: the API returns 409. An adjustment also needs the current item version; stale corrections return 409.

X-Inventory-Client: stockroom is a write-request marker, not authentication. This local demonstration does not implement production sign-in, OAuth scopes or public backend hosting.
